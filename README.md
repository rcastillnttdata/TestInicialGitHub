# Jabalcón

Juego clásico de la serpiente hecho con HTML, CSS y JavaScript vanilla.

## Cómo jugar

1. Abre `/home/runner/work/TestInicialGitHub/TestInicialGitHub/index.html` en un navegador.
2. Pulsa **Iniciar partida**.
3. Mueve la serpiente con las flechas o con **WASD**.
4. Consigue la mayor puntuación posible sin chocar.
